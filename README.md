# Alternative ProAV & Broadcast Tools

A collection of ProAV, lighting, broadcast, and show-control software links. The summaries below are brief introductions; features and licensing can change over time. To suggest an addition, open an issue with the tool's details and why it belongs here.

## Hardware Control, API & Routing Automation

- [Bitfocus Companion](https://bitfocus.io/companion) — Free and open-source control software that connects button surfaces and other interfaces to AV and broadcast systems.
- [OpenAVC](https://openavc.com) — Free and open-source software for controlling and automating AV equipment.
- [Ross DashBoard](https://www.rossvideo.com/products-services/management-systems/control-systems/dashboard/) — Free control and monitoring interface for broadcast equipment and production systems.
- [Central Control](https://centralcontrol.io) — Paid software for controlling and automating AV and live-production equipment.
- [Chataigne](http://benjamin.kuperberg.fr/chataigne/en) — Free and open-source modular software for connecting devices, protocols, and applications in interactive setups.

## Audio, Video & Lighting Cue Playback

- [QLab](https://qlab.app) — Cue-based playback and show-control software for audio, video, and lighting, with a free tier and paid licenses.
- [Show Cue Systems (SCS)](https://www.showcue-systems.com) — Paid cue playback software for theatre and live productions.
- [CSC Show Control](https://www.cscshowcontrol.com) — Paid show-control software for cueing and playback in live productions.
- [Linux Show Player (LiSP)](https://www.linuxshowplayer.org) — Free and open-source cue playback software for live shows on Linux.

## Live Streaming, Vision Mixing & Media Servers

- [OBS Studio](https://obsproject.com) — Free and open-source software for live streaming and video recording.
- [vMix](https://www.vmix.com) — Paid live-production software for video mixing, streaming, and recording.
- [Resolume Arena & Avenue](https://resolume.com) — Paid software for live video mixing, VJ performance, and projection mapping.
- [TouchDesigner](https://derivative.ca) — Node-based software for real-time interactive media and visuals, free for non-commercial use with paid licenses available.

## Stage Presentation & Live Event Graphics

- [EasyWorship](https://www.easyworship.com) — Paid presentation software for worship services, including lyrics, scripture, and media.
- [Logos Proclaim](https://proclaim.logos.com) — Subscription presentation software for churches and worship services.
- [FreeShow](https://freeshow.app) — Free and open-source presentation software for churches and live events.
- [OpenLP](https://openlp.org) — Free and open-source presentation software for worship services.
- [ProPresenter](https://renewedvision.com/propresenter/) — Paid presentation and live-production software for churches and events.
